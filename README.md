# 📰 AI·바이오 보도자료 뉴스레터 편집기

정부 부처 보도자료 링크를 붙여넣으면 AI가 **추진 배경 · 주요 내용 · 기대 효과 및 향후 계획**을 개조식으로 요약하고, 직접 다듬은 뒤 **보기 좋은 HTML 뉴스레터 메일**로 보내는 편집기입니다.

## 왜 만들었나

재정경제부 인공지능경제과는 업무 특성상 과학기술정보통신부, 산업통상부, 중소벤처기업부, 보건복지부의 정책을 자주 참고해야 합니다.
매일 [대한민국 정책브리핑 보도자료](https://www.korea.kr/briefing/pressReleaseList.do)에서 관련 자료를 찾아 읽고, 요약하고, 메일 서식을 맞추는 데 시간이 많이 듭니다.
이 편집기는 그 과정을 **링크 붙여넣기 → AI 요약 → 편집 → 발송** 네 단계로 줄여 줍니다.

## 주요 기능

| 화면 | 기능 |
|---|---|
| **보도자료 편집** | 날짜 탭 만들기 · 링크 여러 개 한 번에 붙여넣기 · AI 자동 요약과 AI/바이오 분류 · 굵게·형광펜(3색) 편집 · 항목 추가/삭제 · 메일 포함 선택 · 카테고리·부처 필터와 검색 · AI 원본으로 되돌리기 |
| **메일 발송** | 제목(`{날짜}` 자동 치환) · 인삿말/맺음말 · 1부(AI)·2부(바이오) 자동 배치 · 순서 변경 · 실제 메일과 같은 PC/모바일 미리보기 · 주소록에서 받는 사람 고르기(BCC) · 테스트 발송 · 발송 이력 |
| **설정** | 메일 서버 연결 확인 · 주소록 추가/삭제 · CSV 가져오기 · 템플릿 관리 |

**정확성을 위한 장치**
- 정책브리핑의 문서 뷰어에서 보도자료 **원문 본문**을 직접 읽어 요약합니다 (사이트 안내문·첨부파일 목록 제외).
- AI에게 "원문에 있는 내용만, 숫자·기관명은 그대로" 규칙을 주고, 답을 정해진 JSON 형식으로 검사합니다.
- 담당 부서·연락처는 AI 추측 대신 원문 맨 아래 **담당 부서 표에서 직접** 읽습니다.
- 모든 뉴스레터에 원문 바로가기 링크가 들어갑니다.

## 기술 구성

| 영역 | 사용 기술 |
|---|---|
| 화면·서버 | Next.js 16 (App Router, Server Actions) · TypeScript · Tailwind CSS |
| 데이터 저장 | Supabase (PostgreSQL, RLS로 공개 키 접근 차단) |
| AI 요약 | OpenAI API + Zod 형식 검사 |
| 본문 수집 | cheerio |
| 메일 | 표(table) + 인라인 스타일 HTML · Nodemailer (SMTP) |
| 테스트 | Vitest |
| 배포 | Vercel |

## 직접 실행하기

```bash
npm install
cp .env.example .env   # 값 채우기
npm run dev
```

`.env`에 필요한 값은 [.env.example](.env.example)을 참고하세요. DB 테이블은 [supabase/migrations](supabase/migrations)의 SQL로 만듭니다.

```bash
npm test        # 자동 테스트
npm run build   # 배포용 빌드
```

> 공개 배포본에서는 메일 서버(SMTP)를 연결하지 않아 **실제 메일 발송은 꺼져 있습니다.** 수집·요약·편집·미리보기는 모두 사용할 수 있습니다.
